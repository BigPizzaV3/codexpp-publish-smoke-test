# 发布流程测试

Codex++ 一键发布的实测包，可以删除

## 安装

在 Codex++ 管理器打开「拓展 → 社区拓展」，搜索 `publish-smoke-test` 点安装；
或从 [Releases](https://github.com/BigPizzaV3/codexpp-publish-smoke-test/releases) 下载 `publish-smoke-test-v<版本>.zip`，解压到 Codex++ 的拓展目录。
